# Calculadora de IMC
Este programa lo desarrollé para el bootcamp de Python en el que estoy participando. El programa solicita:
- El o los nombres del usuario.
- Ambos apellidos.
- Edad.
- Peso en kilogramos.
- Estatura en metros.
Con estos datos te genera un resumen y realiza el cálculo del índice de masa corporal; el cuál adjunta al final del resumen.

## Instrucciones de ejecución
Se ejecuta desde la terminal de Visual Studio Code, al ejecutarse sucederá lo siguiente:
1. Le solicitará su o sus nombres. Es obligatorio introducirlos, el programa está diseñado para no continuar hasta que se haga.
2. Le solicitará su apellido paterno y después su apellido materno. De igual forma es obligatorio introducirlos.
3. Le solicitará su edad. Deberá introducirla en formato de número. De no hacerlo o dejar el espacio en blanco, el programa no continuará.
4. Le solicitará su peso. Deberá introducirlo en formato de número y en kilogramos. De no hacerlo o dejar el espacio en blanco, el programa no continuará. Si se introduce el peso en otra unidad de medida, puede que el programa arroje un resultado erróneo.
5. Le solicitará su estatura. Deberá introducirlo en formato de número y en metros.De no hacerlo o dejar el espacio en blanco, el programa no continuará. Si se introduce la estatura en otra unidad de medida, puede que el programa arroje un resultado erróneo.
6. Si todos los datos fueron introducidos de manera correcta, el programa le arrojará un resumen de estos. Al final de dicho resumen se incluirá su índice de masa corporal con dos decimales.
